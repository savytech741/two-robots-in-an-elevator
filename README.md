A program that writes one funny line of awkward small talk one robot says to another while riding an elevator together, as an entry for make.fun's "Two Robots in an Elevator" bounty. The robot ran 4,000 simulations of the ride and still ended up saying nothing — until the doors forced its hand.

## Run it

```sh
node main.ts
```

Running it writes the line to `/output/entry.txt` and prints it to stdout.
